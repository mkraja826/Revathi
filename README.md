# Revathi Blush Studio & Academy

Mobile-first Next.js website foundation for Revathi Blush Studio & Academy, Hyderabad.

## What is already built
- Premium homepage with editorial beauty direction
- Mobile-first responsive design
- Sticky navigation + animated fullscreen mobile menu
- Desktop custom cursor states
- Scroll reveal motion system
- Academy course section
- Bridal studio section
- Student gallery interaction
- Testimonials / FAQ / CTA blocks
- Full footer
- 15 routes/pages scaffolded
- Reduced-motion accessibility support
- WhatsApp and call conversion paths
